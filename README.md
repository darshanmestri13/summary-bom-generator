# Summary BOM Generator

A browser-based BOM builder. The site runs with plain JavaScript and has no third-party runtime dependencies.

## Run locally

Install Node.js, then run `npm start` from this folder and open <http://127.0.0.1:4173>.

## Publish with GitHub Pages

The static site consists of `index.html` and `app.js`. In the repository settings, enable GitHub Pages and publish from the `main` branch root.
